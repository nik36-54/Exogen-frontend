Build the **initial frontend foundation and design system for EXOGEN**, an enterprise event-risk intelligence platform.

Do NOT build the entire application yet.

The goal of this first phase is to establish an exceptionally polished, premium, modern UI/UX system that we will use for the entire Exogen product later.

---

# PRODUCT CONTEXT

Exogen converts external prediction-market signals into company-specific risk intelligence.

The eventual product flow is:

**Prediction Market Signal → Canonical Event → Risk → Company Exposure → Probability → Risk Score → Dollar Impact → Early Warning**

The product is NOT a betting platform.

It should feel like:

* institutional intelligence
* financial risk software
* premium fintech
* modern enterprise analytics
* Bloomberg/Palantir-inspired information density
* Linear/Stripe-inspired product polish

Do NOT copy any existing company's UI.

Create an original Exogen design language.

---

# PRIMARY DESIGN GOAL

When someone opens Exogen, they should immediately think:

> "This is serious financial intelligence software."

It should NOT feel like:

* sportsbook
* casino
* gambling application
* crypto exchange
* generic AI SaaS
* futuristic neon dashboard
* gaming interface

The interface should be:

**Elegant**
**Minimal**
**Precise**
**Premium**
**Analytical**
**Trustworthy**
**Modern**

Use it carefully for:

* active states
* live signals

* highlights

# TYPOGRAPHY

Use:

**Geist** as the preferred font.

If unavailable, use:

**Inter**

Use a monospace font such as:

**Geist Mono**

for:

* percentages
* dollar values
* timestamps
* IDs
* technical values

Examples:

`61.42%`

`$5,184,200`

`09:42:18 UTC`

Numbers should feel extremely precise and important.

---

# DESIGN RULES

Use:

* 8–10px border radius
* subtle borders
* minimal shadows
* generous spacing
* strong typography hierarchy
* compact but readable information density
* subtle hover states
* subtle transitions

Avoid:

* excessive rounded cards
* excessive glassmorphism
* huge gradients
* glowing neon effects
* excessive shadows
* colorful backgrounds
* cartoon illustrations
* emojis as UI icons
* giant decorative graphics

Use Lucide icons.
